Other Important Algorithms

Learn and visualize various important algorithms including String Matching, Dynamic Programming, and Graph matrices.

Kadane's Algorithm

Kadane's algorithm finds the maximum subarray sum in a one-dimensional array using Dynamic Programming.

Time Complexity

  • Best: O(n)
  • Average: O(n)
  • Worst: O(n)

Space Complexity

  • O(1)

Floyd Warshall Algorithm

Floyd Warshall algorithm finds the shortest paths between all pairs of vertices in a weighted graph using Dynamic Programming.

Time Complexity

  • Best: O(n³)
  • Average: O(n³)
  • Worst: O(n³)

Space Complexity

  • O(n²)

Warshall's Algorithm

Warshall's algorithm computes the transitive closure of a directed graph, determining if there is a path between any two vertices.

Time Complexity

  • Best: O(n³)
  • Average: O(n³)
  • Worst: O(n³)

Space Complexity

  • O(n²)

KMP String Matching

KMP algorithm uses a partial match table to avoid unnecessary character comparisons when searching for a substring.

Time Complexity

  • Best: O(n + m)
  • Average: O(n + m)
  • Worst: O(n + m)

Space Complexity

  • O(m)

Rabin Karp Algorithm

Rabin Karp algorithm is a string matching algorithm that uses a rolling hash function to quickly filter out mismatches.

Time Complexity

  • Best: O(n + m)
  • Average: O(n + m)
  • Worst: O(nm)

Space Complexity

  • O(1)
