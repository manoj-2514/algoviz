Graph Algorithms

Learn and visualize graph traversal and shortest-path algorithms with interactive animations and step-by-step explanations.

Breadth-First Search

BFS explores all neighbors of a node before moving to the next level. It uses a queue and guarantees the shortest path in unweighted graphs.

Time Complexity

  • Best: O(V + E)
  • Average: O(V + E)
  • Worst: O(V + E)

Space Complexity

  • O(V)

Depth-First Search

DFS explores as far as possible along each branch before backtracking. It uses a stack (or recursion) and is used for cycle detection and topological sort.

Time Complexity

  • Best: O(V + E)
  • Average: O(V + E)
  • Worst: O(V + E)

Space Complexity

  • O(V)

Dijkstra's Algorithm

Dijkstra finds the shortest path from a source node to all other nodes in a weighted graph. It greedily picks the minimum-distance unvisited node.

Time Complexity

  • Best: O(V²)
  • Average: O((V + E) log V)
  • Worst: O(V²)

Space Complexity

  • O(V)

Prim's Algorithm

Prim's algorithm finds the Minimum Spanning Tree (MST) of a weighted undirected graph by growing the MST one edge at a time from an arbitrary starting node.

Time Complexity

  • Best: O(E log V)
  • Average: O(E log V)
  • Worst: O(V²)

Space Complexity

  • O(V)

Kruskal's Algorithm

Kruskal's algorithm finds the MST by sorting all edges by weight and adding them one by one, skipping edges that would form a cycle, using Union-Find.

Time Complexity

  • Best: O(E log E)
  • Average: O(E log E)
  • Worst: O(E log E)

Space Complexity

  • O(V)
